# Data format

This page describes the JSON data files produced by the daily update (`update.sh`) and the Markdown tables generated from them.

## Input files

### `data/sandbox_ids.json`

Tracked games only. A JSON object mapping a **page slug** to its **sandbox ID**:

```json
{
  "a-plague-tale-requiem": "64ae027afbd145d9b6e62bd96967fe66",
  "absolute-drift": "9d2f484bbec64aa8ad234b3199dcaf1c"
}
```

This is the list of games for which stats are fetched every day.

### `data/page_mappings.json`

All discovered store pages. Same shape as `data/sandbox_ids.json` (page slug → sandbox ID), but covering every page slug found on the store, not only the tracked ones.

### `data/page_slugs.json`

Local cache: a flat, sorted JSON array of all page slugs found on the store. Regenerated when missing.

### `data/discord_webhook.json`

Local-only file, never committed. Generated by `prepare_webhooks.py` from the `DISCORD_*` environment variables; it maps a keyword (`new`, `free`, `trophy`, `late`, `fix`) to a Discord webhook ID.

## Daily snapshots: `data/YYYY/MM/DD.json`

One file per day, e.g. `data/2025/07/23.json`. A JSON object mapping a **sandbox ID** to its stats:

```json
{
  "d00a1f7b44a14dddab853280118f8580": {
    "numProgressed": 519,
    "numCompleted": 122,
    "maxRarity": 97,
    "averageRating": null,
    "pollResult": []
  }
}
```

| Field | Type | Meaning |
|---|---|---|
| `numProgressed` | integer or `null` | Number of players who unlocked at least one achievement. `null` since the January 22, 2025 leak plug. |
| `numCompleted` | integer or `null` | Number of players who unlocked all achievements (platinum trophy). `null` since the leak plug. |
| `maxRarity` | integer or `null` | Highest achievement unlock percentage (rarity), in percent. `null` since the leak plug. |
| `averageRating` | number (1–5) or `null` | Average store rating; `null` when there are no raters. |
| `pollResult` | array or `null` | Raw rating poll, one element per star bucket, each with a `total` number of raters. |

`null` means "data unavailable", not zero.

Two extra fields are computed in memory when the Markdown docs are generated (they are not stored in the daily files):

- `ratingCount`: number of raters, derived as the maximum `total` across `pollResult` (`src/game_rating_utils.py`).
- `slug`: the page slug, looked up from `data/sandbox_ids.json` (`src/data_utils.py`).

## Generated Markdown tables: `docs/by_*.md`

Six tables, one per sort order:

- [Sorted by Game Slug](by_game_slug.md)
- [Sorted by Average Rating](by_average_rating.md)
- [Sorted by Number of Raters](by_num_raters.md)
- [Sorted by Number of Players](by_num_players.md)
- [Sorted by Number of Platinum Trophies](by_num_platinum_trophies.md)
- [Sorted by Max Rarity](by_max_rarity.md)

Each file starts with a `Last updated on YYYY-MM-DD HH:MM.` line, followed by a Markdown table with the columns:

```
|#|Game Slug|Average Rating|Number of Raters|Number of Players|Number of Platinum Trophies|Max Rarity (%)|
```

Games with a missing stat, inconsistent stats, zero players, or buggy achievements are filtered out of the tables (see `src/data_filters.py`).
